## 1. 项目概述与目标

以 `lease`（单体 Spring Boot 公寓租赁系统，admin :8080 / app :8081）为业务原型，以 `demo_lease_cloud`（Nacos 注册、网关、登录、登录拦截器微服务骨架）为架构蓝本，拆分出完整的微服务系统。

**硬性约束**

- 前端请求路径 `/admin/**`、`/app/**`，请求头 `access-token`，统一返回 `Result{code, message, data}`，成功码 `200`，失效码 `[305, 601, 602]`，参数 schema、错误码语义与 lease **完全一致** → 前端除 baseURL 一行外零改动。
- 数据库：规划阶段只交付 DDL / 测试数据脚本，**不实际建库**。
- 邮箱验证码登录：`getEmailCode` 先**随机生成 6 位数字**存入 Redis（TTL 300s、60s 防重发），**直接返回该数字，不接真实 SMTP**；其余按规范实现。

**源代码只读原则**：以下四个目录仅供参照，**不得修改**：

```
E:\code\test\lease-cloud\lease\              单体业务原型
E:\code\test\lease-cloud\demo_lease_cloud\   微服务骨架样例
E:\code\htmlcss\rentHouseAdmin\              后台管理前端源
E:\code\htmlcss\rentHouseH5\                 H5 用户端前端源
```

## 4. 后端总体架构

```
                 ┌──────────────────────────────────────────┐
 前端 admin_lease │   Gateway :800 (lease-gateway)          │
 前端 user_lease  │   Spring Cloud Gateway + Sentinel       │
                 └───────────────┬──────────────────────────┘
              ┌──────────────────┼───────────────────────┐
              ▼                  ▼                        ▼
   auth-service1001    apartment-service1002     agreement-service1003
   lease-auth-service  lease-apartment-service   lease-agreement-service
   /admin/login/**     /admin/apartment/**       /admin/agreement/**
   /app/login/**       /admin/room/**            /admin/appointment/**
   /admin/info         /admin/attr|facility|     /app/agreement/**
   /app/info           /fee|file|label|term|     /app/appointment/**
                       /payment|region/**
                       /app/room|apartment|
                       /term|payment|region|
                       /history/**
                       内部接口 /inner/**  ▲
                                      │ Feign
   user-service1004  ◄──── Feign ─────┘
   lease-user-service
   /admin/system/**、/admin/user/**
   /inner/**（供 auth 服务调用）
```

要点：

- **网关直连业务服务**，不设 BFF 层，避免 Controller 重复。
- 网关只做路由与可选限流，**不做 JWT 鉴权**；各服务本地拦截器校验 `access-token` 并填充 `LoginUserHolder`。
- 跨域数据（分库后无法 JOIN）一律走 **Feign 内部接口**（`/inner/**`），内部接口不走网关。
- 每个服务只保留 lease 中自己那部分代码，包名沿用 `com.kami.lease.web.admin.*`、`com.kami.lease.web.app.*`、`com.kami.lease.model.*`，共享库放 `com.kami.lease.common.*`。

### 6.2 gateway-service800（port 80，`lease-gateway`）

- `spring.config.import=nacos:application.yml`（共享配置）；`spring.cloud.nacos.server-addr=127.0.0.1:8848`
- 路由表见 §9
- `spring.codec.max-in-memory-size` 调大（文件上传 100MB）；可选 CORS 全局配置
- Sentinel 网关限流沿用 demo：`SentinelGatewayConfig` + 429 BlockRequestHandler

### 6.3 auth-service1001（`lease-auth-service`）

- 控制器（路径与 lease 完全一致）：
  - admin：`GET /admin/login/captcha`、`POST /admin/login`、`GET /admin/info`
  - app：`GET /app/login/getEmailCode`、`POST /app/login`、`GET /app/info`
- 依赖：Redis、`UserFeignApi`、jjwt
- 数据流（**登录逻辑改为走 Feign，不直接碰任何表**）：
  - admin login：校验验证码（Redis `admin:login:{key}`）→ `UserFeignApi.systemUserByUsername` → MD5(password) 比对 + status 校验 → `JwtUtil.createToken(id, username)`
  - app login：`getEmailCode` 随机 6 位数字入 Redis（300s / 60s 防重发），**直接返回该数字** → `POST /app/login` 校验 → `UserFeignApi.userByEmail`，无则 `UserFeignApi.createUser(email, "用户-xxxxxx")` → status 校验 → 发 JWT
  - `/admin/info`：`LoginUserHolder` 取 userId → `UserFeignApi.systemUserById` → `SystemUserInfoVo{name, avatarUrl}`
  - `/app/info`：`LoginUserHolder` 取 userId → `UserFeignApi.userById` → `UserInfo{nickname, avatarUrl}`
- 拦截器：拦截 `/admin/**`、`/app/**`，放行 `/admin/login/**`、`/app/login/**`
- 无业务库；`application.yml` 仅配 Nacos / Redis / jwt；SMTP 配置项留占位注释（不生效）

### 6.5 agreement-service1003（`lease-agreement-service`）

- **admin 控制器**：`/admin/agreement`（saveOrUpdate / page / getById(空路径) / removeById / updateStatusById）、`/admin/appointment`（page / updateStatusById）
- **app 控制器**：`/app/agreement`（listItem / getDetailById / updateStatusById / saveOrUpdate）、`/app/appointment`（saveOrUpdate / listItem / getDetailById）
- `ScheduleTasks` 迁入并 `@EnableScheduling`（每日 0 点：已到期且状态为 SIGNED / WITHDRAWING 的租约置为 EXPIRED）
- 依赖：`ApartmentFeignApi`（common）、`LoginUserHolder`（app 取 user 相关数据）
- **改造点（分库后无跨表 JOIN，全部 Feign 组装，响应字段名与结构不变）**：
  - admin `page`：查询参数 provinceId/cityId/districtId → 先调 `apartment/list-ids-by-region` 得公寓 id 集合；roomNumber → `room/list-ids-by-number` 得房间 id 集合；再在 `lease_agreement` 上按 `apartment_id IN(...)`、`room_id IN(...)` 及自身 phone/name 条件**分页**查询；对分页结果批量调 `apartment/by-ids`、`room/by-ids`、`payment-type/by-ids`、`lease-term/by-ids` 组装 `AgreementVo{apartmentInfo, roomInfo, paymentType, leaseTerm}`
  - admin `getById`：同上单条组装
  - app `listItemByUsername`：按 username 查租约行 → 批量 Feign 组装 `AgreementItemVo`
  - app `getDetailById`：租约 + Feign 取公寓 / 房间 / 图片（`graph/list`，公寓与房间两块）/ 支付 / 租期，组装 `AgreementDetailVo`
  - admin `page`（view_appointment）：按公寓 id 用 `apartment/by-ids` 补公寓名；区划过滤若传参则用 `list-ids-by-region` 转 id 集合过滤

## 7. Feign 内部接口契约

> 内部接口统一返回 `Result<...>`；内部 DTO 中的枚举/状态字段一律用**原生 Integer**，避免跨模块枚举依赖。

### 7.1 UserFeignApi（name = `lease-user-service`）

| 端点 | 出参 |
|---|---|

## 8. JWT / 拦截器 / 统一返回

- `Result` + `ResultCodeEnum` 原样拷贝 lease（前端只认 `code===200`、失效码 `[305,601,602]`）。
- `JwtUtil`：默认 secret 沿用 lease（`kamiv6M2JhrRddyTmuSaM8HCCw2nC3y5`，yml 可覆盖），TTL 1 小时；token 中不含额外 claim，`parseToken` 后从 subject/claims 恢复 userId、username 填充 `LoginUserHolder`。
- `AuthInterceptor`：各服务注册，放行路径可配；`/inner/**` 一律放行（Feign 调用不带 `access-token`）。
- 下游服务均能直接收到网关转发过来的 `access-token` 头（网关默认透传请求头）。

## 10. 接口一致性对照与差异处理

- 后端实现面 = **lease 后端全量接口**（admin 59 个 + app 端汇总），路径/方法/出入参/返回结构与 lease 一一对照（各接口已在 §6 逐服务分配）。
- 返参结构以前端 `src/api/*/types.ts` 为验收基准：`pageItem/page` 返回 `IPage`（`records/current/size/total/...`）；`CaptchaVo{image,key}`、`GraphVo{name,url}`、`AttrKeyVo{...attrValueList}`、`FeeKeyVo{...feeValueList}` 等不变。
- **差异处理（不实现，属前端模板遗留，页面零调用，已核实）**：
  - `/app/region/listAsTree`
  - `/admin/system/index/logout`、`/admin/system/menu/**`、`/admin/system/role/**`、`/admin/system/sysDept/**`、`/admin/system/sysLoginLog/**`、`/admin/system/sysMenu/**`、`/admin/system/sysOperLog/**`
  - `/admin/system/user/listRoleByUserId`、`/admin/system/user/updateRoleListById`
  - `/admin/cmn/dict/findByParentId/${id}`
- 后端与 lease 的行为差异：仅"app 邮箱验证码直接返回 6 位随机数字"（不真正发送邮件），当前阶段行为，已在本文档明示。

## 13. 构建与启动

## 16. 注意事项与风险

- **分页 + 内存过滤不可用**：必须"先 Feign 取 id 集 → SQL `IN` 分页"，已在 §6.5 强制约定。
- `SystemUser.password` 默认 `select=false`，`/inner/system-user/by-username` 需自定义 select 显式带出。
- 枚举入参（`status`、`type` 等 0/1 字符串）依赖 `StringToBaseEnumConverterFactory`，各服务必须注册。
- 网关 webflux 下枚举/ControllerAdvice 不可用，鉴权逻辑不得放网关。
- Windows 绑定 80 端口需要管理员权限（以管理员运行终端/IDEA）；被占用时改网关端口并同步前端。
- `Result` 的 code 值域与前端 `ResultEnum`（SUCCESS=200，EXPIRE=[305,601,602]）强绑定，禁止改动。
- 内部 DTO 状态字段用 Integer；对外 VO 用 `@JsonValue` 枚举，两者不可混用（Feign 反序列化问题）。
